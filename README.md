# IPM System

## 1. Project Description

IPM System is an Inventory and Purchase Management System developed to manage item types, items, stock availability, and purchase transactions.

The application uses React.js for the frontend, Python Django and Django REST Framework for the backend, and MySQL for database management.

---

## 2. Technologies Used

- Frontend: React.js
- Backend: Python, Django
- API: Django REST Framework (DRF)
- Database: MySQL
- HTTP Client: Axios
- Development Tools: Visual Studio Code, MySQL Workbench

---

## 3. Prerequisites and Software Versions

The following software is required to run the project:

- Python 3.12 or above
- Django 5.x
- Django REST Framework
- MySQL 8.x
- Node.js
- npm
- React.js
- Git
